# Rashid Munir — Portfolio

Static one-page portfolio (HTML/CSS/JS, no build step). Terminal identity, one real project (FiberHome HG6145D2 Wi-Fi Extender), light/dark, accessible.

**Live:** https://sheedmunir.vercel.app

## Run

```bash
xdg-open index.html
node tests/structure.test.js
```

## Deploy

Vercel → import repo → Framework Preset "Other", no build command, output directory `.`. Auto-deploys on push to `main`.
